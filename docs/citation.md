# Citing pci

If `pci` helps your work, please cite **the paper** that develops the framework and
**the software**.

## The paper

> Ghorbani, E. and Hackl, J. (2026). *Subsystem Structure as an Inferential Resource for
> Coupled Engineered Systems.* arXiv:2605.27544.
> <https://arxiv.org/abs/2605.27544>

```bibtex
@article{ghorbani2026subsystem,
  author  = {Ghorbani, Esmaeil and Hackl, J{\"u}rgen},
  title   = {Subsystem Structure as an Inferential Resource for Coupled Engineered Systems},
  journal = {arXiv preprint},
  year    = {2026},
  eprint  = {2605.27544},
  archivePrefix = {arXiv},
  url     = {https://arxiv.org/abs/2605.27544}
}
```

The scripts and data of the paper itself are archived separately at
[cisgroup/compositional-inference](https://github.com/cisgroup/compositional-inference).

## The software

The repository ships a [`CITATION.cff`](https://github.com/cisgroup/pci/blob/main/CITATION.cff),
so GitHub's **"Cite this repository"** button generates an up-to-date reference. A BibTeX
entry for version {{ pci_version }}:

```bibtex
@software{ghorbani_pci,
  author  = {Ghorbani, Esmaeil and Hackl, J{\"u}rgen},
  title   = {{pci: Probabilistic Compositional Inference for coupled engineered systems}},
  year    = {2026},
  version = {{{ pci_version }}},
  license = {MIT},
  url     = {https://github.com/cisgroup/pci}
}
```

`pci` is MIT-licensed and developed at Princeton University, Complex Infrastructure
Systems Group.
