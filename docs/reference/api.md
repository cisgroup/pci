# Top level: `pci.solve`

Declarative problem definition. `solve` builds and runs a problem written as YAML, JSON
or a dictionary; `build` instantiates it without solving; `load_config` reads the file
so that keys can be overridden first. Every key is documented on the
[Configuration](../configuration.md) page.
