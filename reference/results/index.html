    Results

    What System.estimate and System.simulate return: posterior mean and standard deviation of every state and parameter of every subsystem, the message time histories, metrics against an attached truth, plots and a pandas export.

    Results dataclass 

    Results(t: ndarray, subsystems: Dict[str, SubsystemHistory], messages: Dict[str, ndarray], truth: Optional[Dict[str, ndarray]] = None, runtime: float = 0.0, mode: str = 'estimate', schedule: str = '', final_covariances: Dict[str, ndarray] = dict())

    Methods:

    Name Description
    state

    Posterior-mean trajectory of a state or parameter, by name ("x2" or "S1.x2").
    estimates

    All trajectories keyed by variable name (qualified when a name is shared).
    message

    Mean message trajectory (length N) of the interface name.
    series

    State/parameter trajectory, or message trajectory when name is an interface.
    rmse

    RMSE against the truth, optionally starting from time start (seconds).
    nrmse

    RMSE normalised by the truth range (or by the true value for constant parameters).
    to_dataframe

    Long-format table with one column per (qualified) variable, its std and the truth when known.

    Attributes:

    Name Type Description
    parameters Dict[str, ndarray]

    Trajectories of all unknown parameters, keyed by name.
